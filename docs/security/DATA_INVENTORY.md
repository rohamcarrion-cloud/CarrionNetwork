# Current data inventory

Evidence: migrations 001–007; server/domain/media/publishing/feeds/storage code.
No analytics ingestion, payment or marketing collection is implemented. User-entered
podcast text/filenames/media can themselves contain personal data. Actual retention
policy and deletion exceptions need legal/product review, not invented durations.

Public RSS uses Show author/copyright/website/text and publication content chosen by
creator, not account email automatically. Public content cannot be recalled from
listeners. Account/data deletion requires reconciling publication history triggers,
foreign keys, shared originals and backups; archive/unpublish is not erasure.

Future only: payments/billing addresses, email delivery logs, directory OAuth secrets,
object-storage identifiers, analytics/IP/device tracking, marketing consent, moderation
cases, exports/deletion jobs. Inventory before implementation, with vendor/access and
retention purposes; none is claimed collected now.
